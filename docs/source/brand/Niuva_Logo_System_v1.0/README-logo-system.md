# Niuva Logo System v1.0

## Locked principle
The original Niuva symbol and original NIUVA wordmark shapes are not redesigned.
This package only creates approved layout and color variants.

## Canonical colors
- Niuva Blue: #6390BB
- Light-mode wordmark: #111827
- Dark-mode wordmark: #F8FAFC
- Reversed logo: #FFFFFF

## Approved configurations
1. Primary: Horizontal lockup
2. Secondary: Stacked/vertical lockup
3. Compact: Symbol only

## Horizontal master geometry
- Wordmark height: 1H
- Symbol height: ~1.15H
- Internal gap: ~1.35X
- X = diameter of the symbol dot
- Alignment: optical, using the visual mass of the symbol body rather than the full bounding box.

## Theme usage
- Light background: blue symbol + #111827 wordmark
- Dark background: blue symbol + #F8FAFC wordmark
- Brand-blue or low-contrast background: full-white reversed logo
- Monochrome dark is included for one-color production use.

## Clear space
Minimum clear space around any lockup: 1X, where X is the symbol dot diameter.

## Usage hierarchy
- Website navbar/header: horizontal
- Footer: horizontal when space permits
- Poster/packaging/square or vertical compositions: stacked
- Favicon/avatar/app icon/small UI: symbol only

## Source fidelity note
The supplied source artwork is raster PNG. These deliverables preserve its existing silhouettes and wordmark shapes rather than vector-tracing them. For a true master SVG/AI/EPS package with mathematically exact original paths, provide the original vector artwork if available.
